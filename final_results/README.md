# Final Results Package

这是本项目的最新成果展示与复现快照（基线日期：2026-09-12）。目录只保留正式输入、赛题、最终论文、最终工作簿、必要的核验记录和与最终结果直接相关的代码；历史版本、实验产物、测试套件、调研草稿和大体积中间回放不纳入本目录。

## 目录

- `data/`：标准化输入数据、数据字典、质量报告、时间维度和题目工作簿模板。
- `problem/`：赛题 `C题.md`。
- `code/`：Q1-Q4 最终复现所需的 Python/Node 源码快照及依赖清单。
- `papers/`：四问最终结果分析论文。
- `results/`：最新正式交付结果。Q3 保留 N0 主口径和 N1 敏感性，Q4 保留 N0/N1 及根目录主文件。
- `支撑材料/`：原始附件、原始模板、处理后数据、数据处理代码、核心程序和主要输出的复核副本。

## 版本口径

Q1 使用 `outputs/01a08b78-ed6b-7e60-b40d-9f266855d1ef/q1/result1.xlsx`；Q2 使用 `q2_review_v2`；Q3 使用 `q3_unified_v1`；Q4 使用 `q4_final`。成果目录中的 Excel、论文和核验 JSON 均从这些最新目录复制，旧目录不会覆盖本快照。

## 复现

代码快照与仓库根目录的 `src/` 同版本。由于求解器保留了仓库级输入/输出路径约定，完整重算应在仓库根目录执行 `src/README.md` 中对应 Q1-Q4 的命令；本目录提供的 `data/` 和 `results/` 用于展示、审计和结果对照。Q2 的因果预测缓存 `results/q2/forecasts.npz` 已随包提供，避免复现时依赖历史输出目录。

复现完成后，应重新运行各问的 `*_verify_delivery.py`，并将新结果与本目录的核验记录比较。不要把 `tests/`、`outputs/*/smoke`、`*_inspect.ndjson` 或实验对比文件复制到成果目录。

## 维护规则

1. 只有通过独立核验、已同步论文且被标记为正式版本的成果，才能进入本目录。
2. 每次更新先在原始 `outputs/` 目录完成重算和核验，再整体替换对应问题的成果文件；不得混用不同版本的论文、Excel、摘要和核验记录。
3. 保持 `data/` 为输入快照，不在成果目录内清洗、平滑或静默修改数据。
4. `code/` 只收录最终复现链直接依赖；测试、探索、敏感性实验和中间转换脚本留在仓库原目录。
5. 新版本更新时同步修改本 README、根目录 `AGENTS.md` 的版本记录，并在 Git 中提交变更。

支撑材料的详细说明见 `支撑材料/README.md`。
