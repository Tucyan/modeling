## 3. 推荐模型与备选

推荐：以144时段确定性储能调度为主模型，完整物理表达采用混合整数线性规划（MILP），以全天计划购电费最小为唯一主目标；用二元变量表达每个时段充放电互斥。当前典型日已验证LP最优解满足完整互斥约束，因此实际计算可采用LP，详见第6节。

| 方法 | 适合程度与理由 |
|---|---|
| MILP | 首选，物理含义明确，144个二元变量，目标和其余约束线性，可报告最优性界和间隙 |
| LP | 有用的松弛下界；若所得解本身互斥且满足完整模型，即可证明该解也是MILP最优解；不要无条件假定每个LP最优解都互斥 |
| 动态规划 | 可以按储能状态递推，但通常需离散化储电量，产生精度与状态规模取舍，本题无必要 |
| 峰谷规则/贪心 | 可作解释或对照，难兼顾未来光伏空间、容量、功率和末端储能 |
| 遗传算法/粒子群 | 本题结构已可精确建模，启发式会增加约束处理及最优性论证负担 |

不存在必须增加预测网络、鲁棒项或退化费用才能求解第一问的依据。相关内容留给后续问题或明确的拓展分析。

## 4. 数学表达

### 已知量与口径

t=0,…,143，Δt=1/6小时。L_t和V_t为区间负载电量、光伏预测电量，单位kWh；p_t为元/kWh。若从功率字段取值，先除以6；已有电量字段直接使用。

充电效率η_c=0.9，放电效率η_d=0.9，往返效率0.81。题目的“充放电效率90%”在本文明确解释为两个方向各90%；往返90%的另一解释可作为单独敏感性分析，不能混在主结果中。

决策变量：g_t购电量，c_t流入电池的母线侧充电量，d_t电池输出到母线的放电量，s_t弃光量，E_t区间起点电池内部储能，z_t充电模式二元变量。电量单位统一kWh；E_144为24:00储能。

### 目标

min C = Σ p_t g_t。

第一问没有紧急购电、调整费、售电收入、折旧费用，不加入未经给定的费用项。

### 约束

1. 母线电量平衡：g_t + V_t − s_t + d_t = L_t + c_t。
2. 储能递推：E_(t+1) = E_t + 0.9 c_t − d_t/0.9。
3. 储能边界：1200 ≤ E_t ≤ 10800，t=0,…,144。
4. 充放电功率及互斥：0 ≤ c_t ≤ (5000/6)z_t；0 ≤ d_t ≤ (5000/6)(1−z_t)；z_t∈{0,1}。
5. 购电与弃光：g_t≥0；0≤s_t≤V_t。
6. 初末条件：E_0=E_144=6000。

5000 kW在本模型中解释为母线侧功率，每时段限额833.333333… kWh，计算时不提前舍入。满功率充电使电池内部增加750 kWh；满功率放电使内部减少925.925926… kWh。

题目要求供电不少于负载。这里用“满足负载的等式+显式弃光”建模，以表达不缺供并记录剩余能源；假设可以弃光、不向外网售电，且不为无用途的过量供电购电。附录初始6000 kWh被应用到典型日，若将第一问理解为自由选择周期起始储能，则应另求 E_0=E_144∈[1200,10800] 的对照，不与固定初始主结果混淆。

### 两个经济解释

- 购电套利只有在 p_高 > p_低/(η_cη_d) 时才有单次往返的价差空间，但实际调度仍受时间和容量限制。
- 日末储能回到日初，不代表充电量等于放电量。该口径下 Σd_t=0.81Σc_t；其差为电池往返损耗。

## 5. 求解及验证路径

1. 输入144条典型日数据，保留原时间和价格精度。
2. 先求LP松弛给出下界、检查是否互斥；若不互斥，用MILP求解。也可直接求MILP并用LP验证下界。
3. 输出求解状态、成本、下界/间隙，复核全部约束，不以成功标志代替物理验证。
4. 独立复算：Σ购电+Σ光伏 = Σ负载+Σ弃光+Σ充电−Σ放电；初末相等时 Σ放电=0.81Σ充电。
5. 费用应不高于无储能可行基准48052.0466元；购电量是否减少需由结果判断，不能由费用下降推断。
6. 若费用最优解存在多解，可在固定主目标最优值的数值容差内，二次最小化充放电吞吐量以去除无效循环；不得随意加权改变主目标。
7. 输出144条购电计划，提取10、12、14、16、18、20点起始的10分钟购电量；按六个4小时区间分别汇总c_t、d_t，填初末储能，并给出全天购电量及费用。

储能表主结果使用母线侧c_t、d_t，论文应标明；内部增减量0.9c_t和d_t/0.9仅作额外核对，不能与主表混用。

求解器使用SciPy的HiGHS接口。追加验证时已通过清华镜像将SciPy 1.18.1安装到项目.local-deps，未修改内置依赖目录。官方资料用于核对数学实现，不替代本地题目：
- SciPy MILP：https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html
- SciPy LP：https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html
- PyPSA储能平衡：https://docs.pypsa.org/v1.2.0/user-guide/optimization/storage/

## 6. LP简化的数值证据与最优性论证

已对当前144时段、充放电效率各90%、初末6000 kWh情形求解LP。去掉二元模式变量，分别保留0≤c_t,d_t≤5000/6，其余约束不变。HiGHS返回Optimal。

| 指标 | LP试算结果 |
|---|---:|
| 全天购电费 | 35126.948589元 |
| 全天购电量 | 59482.698998 kWh |
| 总充电量（母线侧） | 20740.666132 kWh |
| 总放电量（母线侧） | 16799.939567 kWh |
| 总弃光 | 0 kWh |
| 相比无储能节费 | 12925.098002元，26.8981% |
| 同时充放电时段 | 0 |
| 储能最小/最大 | 1200 / 10800 kWh |
| 初始/末端储能 | 6000 / 6000 kWh |

最优性理由：令F_M为完整MILP可行域，F_L为LP松弛可行域，则F_M⊆F_L，从而C_L≤C_M。此次LP最优解x_L在1e-7 kWh容差内满足全部完整模型约束，包括充放电互斥，因此可为其赋予二元模式，得到C_M≤C(x_L)=C_L。两边合并得到C_M=C_L，即该LP解在求解数值容差内也是完整模型的全局最优解。这里证明的是当前算例，不能推出任意改动后的数据或目标都可以无条件忽略互斥。

复核证据：母线平衡最大残差1.14e-13 kWh，状态递推最大残差8.82e-13 kWh，全天电量平衡误差3.64e-12 kWh。另从保存的CSV重新读取，独立检查144条时间键、非负性、功率上限、弃光上界、状态连续、储能范围、初末条件与互斥，均通过。复算费用35126.948589289636元。

验证输出：`outputs/q1_model_validation/summary.json`、`outputs/q1_model_validation/lp_schedule.csv`。这些是模型讨论证据，不代替题目要求的result1.xlsx和论文指定表格。

## 7. 两项假设的敏感性比较

用户已明确当前只讨论第一问模型与假设，暂不制作结果表。以下数值用于比较解释对模型的影响，不作为新增正式交付表。

| 充放电效率解释 | 初始电量条件 | 日购电费（元） | 求解返回的初始电量（kWh） |
|---|---|---:|---:|
| 两个方向各90% | 固定6000 | 35126.948589 | 6000 |
| 两个方向各90% | 仅要求日初=日末，初值可优化 | 35118.598589 | 8550 |
| 往返90%，两方向对称取√0.9 | 固定6000 | 33801.495542 | 6000 |
| 往返90%，两方向对称取√0.9 | 仅要求日初=日末，初值可优化 | 33793.775027 | 8428.291755 |

四个情形均取得LP最优解，并通过功率、储能、平衡、初末及互斥检查。自由初始电量栏只是求解器返回的最优解之一，没有证明该初值唯一。

结论：

1. 在单向各90%口径下，自由选择初始电量仅减少8.35元/日，约0.024%。主模型仍建议固定6000 kWh，以使用附录条件；将自由初值作为周期稳态解释的对照，不因为费用稍低而舍弃题设初始状态。
2. 固定初值下，往返效率90%的对照比主模型少1325.45元/日，约3.77%。效率定义对结果影响更明显，应在论文假设和状态方程中明确写出。
3. 只给往返效率0.9，仅确定η_cη_d=0.9，不能单独确定两个方向效率。本对照额外采用对称效率η_c=η_d=√0.9。由于内部储能容量约束存在，不同效率分解未必得到相同计划，因此不能把对称分解说成题目直接给定。
4. 两项假设变化都没有改变这四次求解中LP最优解互斥的事实，支持当前问题优先采用LP计算，但每次仍应做互斥校验。

可复现计算位于 `src/q1_assumption_probe.py`，比较记录位于 `outputs/q1_model_validation/assumption_sensitivity.json`。
