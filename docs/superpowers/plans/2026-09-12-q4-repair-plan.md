# 第四问问题修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复第四问解答中已发现的口径、结果呈现、审计验证和复现问题，使模型、代码、论文、Excel及审计载荷对同一正式结果保持一致。

**Architecture:** 先冻结唯一的Q4-3日内价格更新口径，并补足候选选择规则和测试；再按修复后的口径重新进行必要的短窗口、1月选择和334天正式回放；最后从正式N0账本自动生成四个指定日期论文表格，补齐Excel逐格验证、预测审计载荷、复现说明和状态表。不会把旧口径结果与新口径结果混合使用。

**Tech Stack:** Python、NumPy、pandas、SciPy/HiGHS、pytest、openpyxl只读核验、`@oai/artifact-tool`工作簿导出、Markdown。
