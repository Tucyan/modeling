数据预处理与标准化
---------

为保证后续购电决策、储能调度及多时段滚动优化中各类数据在时间尺度和物理含义上的一致性，本文首先对题目所给负荷、光伏功率、电价、光伏预测数据以及结果模板进行检查和预处理。处理过程中遵循“保留原始信息、修正格式异常、统一时间基准、避免提前引入模型假设”的原则，不对正常观测值进行主观删除或平滑。

### 1. 原始数据及模板存在的问题

对附件进行逐项检查后发现，原始数据本身完整性较好，未出现明显的数值缺失或异常负值，但在时间表示、日期存储和结果模板中存在若干可能影响后续建模的问题。

首先，题目中的负荷、光伏功率和电价数据均以 10 min 为一个时间间隔，一天共包含 144 个数据点。原始附件中时间字段实际表示各 10 min 区间的**结束时刻**，例如首个数据点标记为“0:10”，其实际对应的应为 (0{:}00\sim0{:}10) 时间段。与此同时，附件1的时间列还存在 Excel 时间数值与文本字符串混合存储的现象，即部分时间以 Excel 时间序列值保存，后续时间又以“10:10”等文本形式保存。如果直接利用原始时间字段进行排序、匹配或表连接，容易产生类型不一致和时间错位问题。

其次，附件2和附件4采用“日期×时间”的宽表形式，每日包含 144 个时刻，其中最后一个时刻以“0:00+1”表示次日0时。该表示虽然能够描述一天的结束位置，但不适宜直接作为优化模型中的时间索引，否则容易将次日 (0{:}00\sim0{:}10) 错误地纳入当日计算。

再次，附件3中的光伏预测数据每天分别在 0:00、6:00、12:00 和 18:00 发布一次未来24 h预测，但原始表格只在每日0:00对应行明确记录日期，其余三个预报时刻的日期单元格为空。由于这些空值采用 Excel 共享字符串方式存储，部分读取工具可能将其误识别为内部索引值，从而导致日期解析错误。此外，该附件预测时间尺度为1 h，而负荷、电价和实际光伏数据时间尺度为10 min，两类数据不能在数据清洗阶段直接进行简单一一对应。

最后，对题目提供的结果模板进行检查发现，购电量相关模板的时间段整体向后偏移一个10 min区间。原模板以“0:10–0:20”作为第一个时间段，并在末尾包含“0:00–0:10+1”，与题意要求的每日 (0{:}00\sim24{:}00) 调度范围不一致。若直接使用该模板，会造成计划购电量与原始负荷、光伏和电价数据整体错位一个时间步。

各类问题及处理方式概括如下。

| 问题                       | 处理方式                     | 处理目的            |
| ------------------------ | ------------------------ | --------------- |
| 10 min时间点表示区间结束时刻        | 重建0～143的统一时间序号           | 消除时间点与时间区间含义混淆  |
| 附件1时间字段存在数值、文本混合         | 不再以原始时间字段作为主键            | 避免排序、连接和解析异常    |
| “0:00+1”表示方式特殊           | 统一转换为23:50–24:00         | 保证每日恰好包含144个时间段 |
| 附件3的6:00、12:00、18:00日期为空 | 根据当日0:00日期向下补齐           | 恢复完整预报发布时间      |
| 附件3为1 h预测，其余数据为10 min    | 预处理阶段保留原时间尺度             | 避免提前引入未经验证的插值假设 |
| 结果模板时间轴整体后移10 min        | 修正为0:00–0:10至23:50–24:00 | 保证输出与模型决策时段完全对应 |
| 功率单位为kW，而优化涉及分时段电量       | 增加对应10 min电量变量           | 便于能量平衡和购电费用计算   |

### 2. 统一10 min时间基准

为避免不同附件时间格式不一致带来的影响，本文不直接采用原Excel中的时间值作为索引，而是定义统一的时间编号

[  
k=0,1,\ldots,143,  
]

其中第 (k) 个时间段表示

[  
\left[\frac{k}{6},\frac{k+1}{6}\right)\text{ h}.  
]

因此，一天的144个时间区间统一表示为

[  
0{:}00-0{:}10,\quad  
0{:}10-0{:}20,\quad\ldots,\quad  
23{:}50-24{:}00.  
]

例如，原始数据中标记为“0:10”的第一个观测值被解释为 (0{:}00\sim0{:}10) 区间对应的数据，而不是 (0{:}10\sim0{:}20)。采用固定时间编号后，各附件之间的数据匹配均通过“日期+时间编号”完成，从而避免由Excel时间类型、文本格式及跨日符号造成的匹配误差。

该处理同时使负荷、实际光伏、电价以及购电决策变量可以在同一个10 min时间尺度上进行逐项对应，为后续能量平衡约束提供统一的时间基础。

### 3. 功率与电量的统一

附件中负荷和光伏数据的单位均为 kW，而题目要求给出各10 min时间段内的购电量、充电量和放电量，因此需要进一步将功率转换为对应时间段内的电量。

由于每个时间步长度为

[  
\Delta t=\frac{10}{60}=\frac{1}{6}\text{ h},  
]

对于任意功率 (P_t)，其对应的10 min电量为

[  
E_t=P_t\Delta t=\frac{P_t}{6}.  
]

因此分别计算负荷电量和光伏发电量

[  
E_t^{L}=\frac{P_t^{L}}{6},  
\qquad  
E_t^{PV}=\frac{P_t^{PV}}{6}.  
]

预处理过程中仍完整保留原始功率数据，同时增加对应的10 min电量字段。这样既可利用功率数据进行曲线分析和预测，也可直接利用电量数据建立储能状态转移、购电量平衡和购电费用模型，避免后续模型中反复进行单位换算。

### 4. 年度实际数据的整理

附件2分别给出了2025年全年实际负荷和实际光伏发电功率，附件4给出了全年实时电价。三类数据均包含365天、每天144个10 min观测点。

本文首先统一日期格式，然后以

[  
(\text{date},k)  
]

作为唯一索引，将同一天、同一时间区间的实际负荷、实际光伏和电价进行对应。经检查，全年日期从2025年1月1日至12月31日连续，共形成

[  
365\times144=52560  
]

个10 min时间样本。

整理后，每个样本同时具有实际负荷、实际光伏、电价及对应10 min电量等信息，可作为后续实际运行过程的基础数据。该结构能够直接用于计算实际供需缺口、紧急购电量以及实际运行费用。

需要特别指出的是，附件2和附件4中的数据属于实际观测结果。对于要求“每日0:00制定当日购电计划”的问题，不能直接将当日尚未发生时刻的实际负荷或实际光伏作为计划阶段的已知条件，否则会产生未来信息泄漏，使所得策略具有不现实的先验信息。因此本文在后续建模中将“计划阶段可获得的信息”和“实际运行阶段用于结算的信息”严格区分。

### 5. 光伏预测数据的整理

附件3每天在0:00、6:00、12:00和18:00分别提供未来24 h的光伏功率预测。针对部分预报行日期为空的问题，本文利用每天0:00记录的真实日期对同日其余三个预报时刻进行日期补齐，并进一步构造完整的预报发布时间。

对于某日预报发布时间 (T)，将“预报第 (h) 小时”统一解释为未来第 (h) 个小时预测信息，并记录其预测提前量 (h)。由此，每年共得到

[  
365\times4\times24=35040  
]

条小时级光伏预测记录。

由于原始光伏预测时间分辨率为1 h，而优化决策时间尺度为10 min，本文在数据预处理阶段并未直接将小时预测插值至10 min。原因在于不同插值方法，例如分段常数、线性插值或基于光伏变化规律的曲线插值，会直接改变优化模型实际接收到的预测信息，应作为后续预测数据重构方法的一部分进行论证，而不应作为单纯的数据清洗操作提前确定。

经过该处理，可以直接比较不同发布时间、不同预测提前量下的光伏预测误差，并为第三问中的6:00、12:00和18:00滚动调整策略提供时间一致的预测输入。

### 6. 结果模板修正

根据统一时间轴，对题目提供的结果模板进行同步修正。所有计划购电量和调整购电量相关字段均统一为144个10 min时间段，起始时间改为

[  
0{:}00-0{:}10,  
]

结束时间改为

[  
23{:}50-24{:}00.  
]

删除原模板中由于时间整体后移产生的次日“0:00–0:10+1”区间，使结果模板与负荷、光伏、电价及优化决策变量严格一一对应。

对于充放电量和紧急购电量等输出，原模板中的省略行仅视为格式示例，不作为实际数据长度限制。后续计算时根据完整日期范围和实际发生的紧急购电区间生成结果，从而避免仅按照模板示例行数输出而造成信息缺失。

### 7. 数据质量检验

完成上述处理后，对数据进行完整性和一致性检查。全年负荷、实际光伏和电价数据均具有完整的365天记录，每天均包含144个10 min时间点；未发现数值型缺失值，也未发现负的负荷或光伏功率。光伏夜间功率为0属于正常物理现象，因此予以保留，不视为缺失值或异常值。

附件3每天均包含0:00、6:00、12:00和18:00四次预测，每次均包含未来24 h预测值。经日期补齐后，各日预测发布时间能够唯一确定，未发现重复的“日期—发布时间—预测提前量”组合。

同时检查所有标准化后的日期—时间组合，保证每一个10 min区间均能够唯一对应负荷、光伏和电价数据。由于未发现明显错误的数值观测，本文未采用均值填补、异常值删除或截尾等可能改变原始数据分布的处理方法，从而最大限度保留题目所给数据的信息。

### 8. 预处理结果的作用

经过上述处理后，原始附件中的各类数据被统一到明确的时间语义和物理量体系下。典型日电价、负荷及光伏预测数据可直接用于第一问的确定性日内优化；全年实际负荷和实际光伏数据可用于第二问之后的逐日仿真与紧急购电计算；小时级光伏预测数据能够按照预测发布时间和预测提前量调用，用于第三问的滚动修正；全年实时电价则可进一步用于第四问的动态电价情景。

更重要的是，统一的10 min时间索引使“计划购电—光伏出力—负荷需求—储能充放电—紧急购电”能够在同一时间尺度下建立能量平衡关系，同时将预测信息与实际信息分开存储，为后续构建无未来信息泄漏的日内优化和滚动优化模型提供可靠的数据基础。
