# 第二问小幅修订：连续影子选模与开放评价末端

本补充对应独立目录outputs/q2_incremental，原v2论文、Excel及Q3接口保留。仅调整评价末端和历史选模环境，日前T0目标6000、0.8分位数、F0反馈、效率及容量约束保持一致。

## 思路构建与边界

题面给定的是1月1日初始6000 kWh，未要求年末恢复。新方案正常运行到12月31日，报告期末库存，不人为按5倍价补库存。T0每日规划末端6000仍是额外规划假设，并不要求实际每日或年末恢复；此前T0/T1对比仍作为该假设的实验依据。

M1/M3/M4影子系统均从1月15日6000 kWh连续运行，取消影子窗口末日特殊动作。月初只累加此前最多56天的真实历史执行费用，2月也使用此前1月历史选择；实际系统沿用1月待机后2月1日6000的既有初始化。实际月初继承自身SOC，重新计算计划，影子SOC和费用均不拼入实际账本。

连续影子历史消除了反复重置，却不保证与实际切换时SOC相同。窗口内各候选的初末库存也不同，原始历史费用排名可能受库存消耗影响；monthly_selection.csv同时列出窗口初末SOC和切换日影子/实际SOC。此处是历史策略选择启发式，不声称同状态最优动作选择或严格随机动态最优。初始1月实际待机、F0贪心和预测MAE筛选仍是现有限制。

## 分位数校准诊断

对净负载逐槽计算经验覆盖率P(实际≤预测分位数)及Pinball Loss；单位为每10分钟槽kWh。分位数只由当日以前56天残差构造，季节覆盖率是事后诊断，不参与回调参数。目标0.8源于单期无储能的经济解释，在本方案不是全日最优或联合可靠性保证。

| 预测 | 季节 | 槽数 | 覆盖率 | Pinball/kWh |
|---|---|---|---|---|
| P0 | 总体 | 48096 | 77.93% | 16.7134 |
| P0 | 春 | 13248 | 74.05% | 15.8613 |
| P0 | 夏 | 13248 | 78.78% | 22.7868 |
| P0 | 秋 | 13104 | 79.65% | 13.8792 |
| P0 | 冬(2、12月) | 8496 | 80.00% | 12.9432 |
| P1 | 总体 | 48096 | 78.81% | 15.8779 |
| P1 | 春 | 13248 | 76.30% | 15.6806 |
| P1 | 夏 | 13248 | 78.74% | 20.2074 |
| P1 | 秋 | 13104 | 82.12% | 14.1785 |
| P1 | 冬(2、12月) | 8496 | 77.72% | 12.0553 |

总体覆盖率P0为77.93%、P1为78.81%，均略低于80%目标；春季分别为74.05%、76.30%，存在更明显低覆盖。故将本方法称为历史残差分位数修正，不能声称已达到稳定80%覆盖。P1总体Pinball较低，但仍不能直接推出储能购电费最优。本轮仅补诊断，不用这张全年统计表反向调高春季参数。
