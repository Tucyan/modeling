# 第二问模型、数据处理与评估方案讨论

日期：2026-09-11。范围：方案讨论及历史预测基准诊断，尚未训练复杂模型、求解第二问完整调度或生成result2.xlsx。

后续文献核查与实验细化见《第二问文献依据与实验设计》：正式比较以该文M0—M4五组方案及两个参考组为准，本文实验编号为早期设计。结论仍需实际回测验证。

## 1. 推荐路线

建议采用“分别预测负载和光伏—校准净负载误差—风险感知的日前优化—因果运行回测”。

首轮主方案为：**负载周周期基准及回归修正、光伏历史曲线及梯度提升候选、净负载分位数校准、日前LP/MILP调度**。完整物理约束沿用第一问，加入固定计划购电、实际紧急购电和运行规则。**场景随机规划作为增强对照**，在同口径回测中证明能降低总成本或尾部风险后，再考虑升级为主模型。

需要多个模型比较和消融，不必强行融合。负载与光伏各用合适方法，本身就是合理组合；预测器加权融合还需额外证据。

## 2. 信息边界

- 附件2是实测，不是每天0点已知的未来曲线。每天0点只用此前可观测历史及日历信息预测未来144个时段。
- 第二问用附件1的重复日电价，不使用合并表中的附件4波动电价，也不使用附件3官方光伏预报。
- 常规计划购电量$g_{i,t}$在0点固定，不进行日内合同调整；短缺通过$e_{i,t}$紧急补购。
- 计划电量是否全部利用，不改变计划收费：

$$
C_i^{\mathrm{tot}}=\sum_t p_tg_{i,t}+5\sum_t p_te_{i,t}.
$$

不能按少用量少付钱，也不能以普通价格随时增加购电而绕开5倍紧急电价。

## 3. 数据诊断与历史基准

重新核查：52560条、365天、每天144条，负载与光伏无缺失，日期—时段键无重复。暂未发现需要重新清洗的依据。

按每天0点只读取此前日期，预测2025-02-01至12-31共334天，MAE如下，单位kW。

| 目标 | 昨天同槽 | 上周同槽 | 过去7天同槽均值 | 过去7天同槽中位数 |
|---|---:|---:|---:|---:|
| 负载 | 650.02 | **176.80** | 781.21 | 626.94 |
| 光伏 | 185.35 | 214.69 | **153.40** | 157.83 |

负载上周同期基准WAPE为3.83%，光伏过去7天均值基准WAPE为6.45%。负载周周期很强，光伏近期平均曲线也形成有效基准，复杂模型须证明额外收益。

全年44.79%的光伏记录为0，普通MAPE存在零分母；全天MAE可能被夜间零值稀释。需同时报告总体和发电活跃时段误差。用实际光伏>1 kW筛选仅可作事后评价分组，不可用当天真实发电窗口生成日前特征。

月平均光伏功率存在明显变化，1月约1589.18 kW、8月约2915.99 kW、12月约1513.84 kW，不能只用固定全年曲线。这些全年统计只能用于探索，不得作为过去预测时的未来已知输入。

本轮为探索性历史回测。各次预测没有读未来，但依据全年成绩选模型仍有研究者层面的选择偏差，不能称为独立盲测。正式方案需预先规定滚动选模与调参程序。尚未计算第二问完整调度成本，不能由MAE宣布费用最优。

诊断依据保存于outputs/q2_discussion中的historical_baselines.json、baseline_daily_metrics.csv、baseline_monthly_metrics.csv。

## 4. 进一步数据处理

需要构造面向预测时点的建模数据，不需无依据地重做清洗。

| 工作 | 处理方式 | 要避免的问题 |
|---|---|---|
| 字段隔离 | 附件2负载光伏与时间键，另关联附件1价格 | 错用附件3/4 |
| 日期级样本 | 一个0点预测起点对应144个目标，保留发布时间、目标时间 | 随机拆分相邻时段 |
| 日历特征 | 时刻周期编码、星期、周末、年内日序；调休节假日需核实来源 | 忽略周周期 |
| 历史同槽特征 | 前1、2、7、14、21天值，7/14/28天统计与历史同星期均值 | 只用昨天，或平均掉工作日差异 |
| 日级特征 | 昨日总负载、历史光伏总量、前日形状、近期趋势 | 缺少水平变化 |
| 标准化/编码 | 只在当次训练集拟合，树模型不强制标准化 | 全年均值、方差泄漏 |
| 光伏约束 | 非负预测；夜间规则来自已知物理信息或过去数据 | 按未来日照窗口修正 |
| 误差库 | 保存过去滚动预测误差及发布/目标时刻 | 用样本内残差低估风险 |
| 可用性审计 | 每个特征标注最新来源时间及训练截止时间 | 无法证明无泄漏 |

当天0点预测14:00，不能用当天13:50实测作“滞后一期”。对10分钟长表直接shift(1)仍会泄漏；本轮先转成日期×时段矩阵，再按日期移位。

一年只有365条完整日曲线，1月仅31天，不能将52560条记录当作独立日型样本。初始阶段减少参数自由度。年内日序虽事前可知，仅凭1月不能可靠学习全年季节响应，应随历史增加更新。

不建议删除真实尖峰、将零光伏填成非零、居中平滑、双向插值或将主调度直接降为小时粒度。暂不强行补天气；若增加天气，需要带历史发布时间的预报档案，未来实测天气也会泄漏。

## 5. 预测模型候选

### 5.1 负载

$$
\widehat L_{i,t}=L^{\mathrm{act}}_{i-7,t}
+f_L(\text{当时可用的日历、历史水平与趋势特征}).
$$

先用$f_L=0$的周季节朴素基准，再比较Ridge残差回归和梯度提升树。历史不足时回退到可计算的简单基准。复杂模型须证明对晚峰、季节变化或费用的改善。

### 5.2 光伏

以过去7天同槽均值为基准，比较近期加权曲线与梯度提升树，特征仅来自历史同槽、历史日发电量、时刻和年内日序。可比较点预测和分位数预测。梯度提升回归支持分位数损失，具体效果仍需本题验证。[官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html)

主方案分别预测负载与光伏，直接预测净负载作对照。风险校准关注$\varepsilon^N=\varepsilon^L-\varepsilon^V$。不能把“负载80%分位数减光伏20%分位数”直接当净负载80%分位数，误差相关性必须考虑。

首轮不推荐LSTM、Transformer或大量模型堆叠：初始日样本有限，没有天气预报输入，并已有强简单基准。

## 6. 调度模型

### 6.1 点预测直接调度

将预测负载与光伏代入第一问物理模型，产生购电和储能轨迹，再真实运行回测紧急费用。它是必要对照，但不能主动权衡多买电与5倍补购。

第二问未要求每日回到6000 kWh。实际状态应跨日承接，终端条件另选并对算法一致；若首版采用日初日末相等，须标明是附加策略约束。

### 6.2 首轮主方案：分位数校准＋日前LP/MILP

用过去滚动预测误差构造分时段或时段组分位数，对净负载做风险修正，再联合优化储能和购电。原负载光伏物理量仍保留，风险余量如何进入约束须写清楚，不把修正净负载叫作实测。

以无储能、单时段、无退款的简化问题解释风险方向：

$$
\min_{g\ge0}pg+5p\,\mathbb E[(N-g)_+].
$$

分布连续、最优点位于内部时，一阶条件为$F_N(g)=0.8$。5倍紧急电价确实支持适度保守的计划，但不能规定全题一律取80%分位数，储能跨时段耦合、终端状态、误差及运行规则都会改变合适水平。

建议只在过去验证中比较少量水平，例如0.5、0.7、0.8、0.9，以总费用和尾部风险选择，而不固定“加10%余量”。1月样本少时合并相邻时段或收缩估计，不单独拟合144条高自由度尾部分布。

### 6.3 增强对照：场景随机规划

$$
\min\sum_t p_tg_{i,t}
+5\sum_{\omega\in\Omega_i}\pi_\omega\sum_t p_te^\omega_{i,t}.
$$

加入储能、功率、平衡、弃光和终端约束。日前$g$在场景间相同，后续动作是否随场景变化须受信息限制。

场景保留日内连续误差及负载—光伏误差相关性，优先按历史整日或时间块联合抽样，不逐时独立加噪声。生成后保持物理量非负，记录概率和方法。

不能让每个场景的储能从0点就知道该场景全天实际路径，然后将其费用当作可实现成本。可选择共享日前储能轨迹并限制补救，使用带非预见性约束的场景树，或将两阶段方法标为乐观近似并通过外部因果控制器评价实际效果。

场景方法更直接表达期望费用，但实现较复杂；需证明优于简单分位数校准后再升级。CVaR留作进一步风险增强，不一次引入过多参数。

## 7. 因果运行协议

首版建议：

1. 0点冻结购电计划及储能参考轨迹。
2. 区间开始时，用当前储能、已发生观测和原预测确定储能动作，不读取完整区间未来均值。
3. 区间真实量实现后，紧急供电自动覆盖缺口，记录费用和可行的剩余能源处置。
4. 更新储能与历史进入下一时段。若允许实时减充、增放或更新轨迹，应明确测量及控制频率，各算法权限一致。

若用10分钟真实均值模拟实时反馈，需明确“区间内可测量并跟踪功率”的近似，不声称区间开始时已知未来10分钟均值。固定动作与反馈修正可作对照。

储能控制更新不等于改变普通购电合同。按量收费后合同电量可能富余，弃光$s$不能表示全部剩余；应说明接收、拒收但不退款或其他可行处置，不能凭空消失。

## 8. 多模型验证及融合

先筛选预测器，再让少量优胜者进入调度回测，不穷举全部组合。

| 方案 | 内容 | 验证的增量 |
|---|---|---|
| S0 | 强基准预测＋点预测调度 | 起点 |
| S1 | 改进预测＋点预测调度 | 预测是否节费 |
| S2 | 与S1相同预测＋分位数校准 | 校准是否值得 |
| S3 | 同一预测及误差＋场景调度 | 场景是否优于简单校准 |
| S4（有证据再做） | 预测融合＋与S2相同调度 | 融合独立收益 |

价格、终端规则、运行控制权限相同。全年策略各自承接其实际储能，不每日重置6000；纯单日受控消融可给相同日初状态，但与全年闭环结果分开。

只有两个预测器的历史样本外误差互补，且后续验证降低误差或费用，才做非负加权融合。权重用过去验证拟合，不能按全年表现反推过去每天最优权重。多模型结果相近也不能代替物理验证。

## 9. 性能评价

### 9.1 时间顺序

采用每天0点为起点、一次预测144时段的滚动回测，不随机拆10分钟记录，也不用单步成绩代表全天预测。滚动起点验证只用目标前历史训练，可评价多步预测。[作者教材](https://otexts.com/fpp3/tscv.html)

- 1月为初始训练、内部验证和暖启动。不同滞后长度起始日期不同，不足时回退。
- 2月1日起每日先冻结预测和计划，再读取实测评价，最后更新历史。
- 分位数、超参数、融合、场景和标准化都只用当日前数据校准。
- 树模型早停也应时间有序，避免随机验证。官方示例说明随机切分可导致过于乐观评价。[scikit-learn时序示例](https://scikit-learn.org/stable/auto_examples/applications/plot_time_series_lagged_features.html)
- 固定开发段调好的参数只能用于其后日期，不能调完半年再回填2月并称当时可执行。
- 本轮看过全年基准，最终如实称历史滚动回测，不包装为独立盲测。

### 9.2 预测指标

| 指标 | 作用 | 注意事项 |
|---|---|---|
| MAE | 平均误差 | 负载、光伏、净负载分别报告，注明单位 |
| RMSE | 大误差敏感 | 不单独代表费用 |
| WAPE | 跨量级比较 | 总绝对误差/总绝对实际量，净负载避免正负抵消 |
| Bias | 系统性偏差 | 统一实际−预测 |
| 分位数损失 | 分位数准确性 | 各分位水平分别报告 |
| 覆盖率及区间宽度 | 校准与实用性 | 不只追求宽区间高覆盖 |

光伏同时报告全天与活跃时段。可诊断高价时段净负载低估，但$5p_t[\varepsilon^N]_+$忽略储能，不等于真实紧急费用。

### 9.3 决策指标：最终选型重点

1. 输出期总费用及计划费、紧急费分解。
2. 紧急量、发生天数、连续事件数、最大单日紧急量。
3. 日费用高分位数、最差天及相对同日公平基准的费用差。
4. 弃光、未利用合同量、储能损耗、吞吐量、边界停留；不虚构退化单价。
5. 最终缺供、SOC越界、功率越界、同时充放电、状态跳变均须在容差内为0。
6. 计算时间、失败率、最优性界及可行回退。

先满足物理和信息约束，再以总费用为主、兼顾风险稳定性。MAE最小、计划购电最少、紧急量最少与总费用最低不是同一目标。

### 9.4 公平性与统计稳定性

- 无储能基准也按日前计划收费及5倍补购，不假设事后全部按普通价买缺口。
- 完美信息下界须放宽同一模型、跨日范围及端点条件；每天强制循环的第一问式最优值相加，不保证是连续第二问的下界。
- 统一全年期末储能约束或终值处理，避免靠耗空电池省钱。
- 报告分月、星期组、光伏强弱及四个指定日期，不只展示指定日期。
- 比较配对日成本差，可按连续周块配对重采样形成置信区间；相关更长则调整块长并做敏感性，不把48096个测试时段视作独立样本。
- 场景固定随机种子并少量变种子检查稳定性。
- 单独消融周周期特征、风险校准、储能反馈与预测融合，每次只改关键机制。

## 10. 推进顺序

先确定储能控制权限、合同过剩和跨日终端规则；再构造0点特征及误差日志，跑强基准；接着比较回归和梯度提升；最后在统一因果执行器中比较点预测、分位数及必要的场景增强。

当前推荐有初步数据依据，最终模型仍应由完整费用回测决定。本轮没有认定复杂预测器或第二问调度已最优。
